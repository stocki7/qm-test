# Nachweise (Evidence)

Hier landet alles, was zeigt, dass ein Ziel erreicht wurde: Screenshots, Logs, Messwerte, Lasttest-Reports.

## Benennung
`YYYY-MM-DD_Z<Ziel-Nr>_<kurzbeschreibung>.<ext>`

Beispiele:
- `2026-11-18_Z05_nmap-portscan.txt`
- `2026-12-08_Z04_restore-test.log`
- `2026-12-09_Z02_k6-lasttest-50-spiele.png`

## Regeln
- Jeder Nachweis wird in `docs/zielmatrix.md` verlinkt.
- Keine Secrets, IPs von Privatgeräten oder personenbezogenen Daten in Screenshots/Logs (vorher schwärzen).
- Große Dateien (> 5 MB) nicht ins Repo, sondern verlinken.
- Nachweise sofort ablegen, nicht erst vor der Abgabe.
